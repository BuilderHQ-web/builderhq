# BuilderHQ iOS (native)

The Swift / SwiftUI rebuild of the BuilderHQ mobile app. Replaces the
React Native + Expo build at `mobile/`.

## Why native

The polish bar BuilderHQ is targeting (Linear / Revolut / Airbnb /
Apple's own apps) is consistently set by native iOS. The RN work in
`mobile/` informed the design system; this is the production target.

The Bubble + BDK Native mobile app stays live serving existing users
until this ships to TestFlight, then App Store.

## Bring it up locally

Prereqs:

- macOS with Xcode 15+ (`xcode-select --install` for command-line tools)
- [Homebrew](https://brew.sh)

One-time setup:

```bash
brew install xcodegen
cd ios-native
xcodegen generate
open BuilderHQ.xcodeproj
```

In Xcode:

1. Select the `BuilderHQ` target → **Signing & Capabilities** tab
2. Set your **Team** to the Apple Developer account that owns the
   `com.builderhq.app` bundle identifier
3. Press ⌘R to run on the iPhone 15 Pro simulator

## Conventions

- **SwiftUI-first.** UIKit only when a SwiftUI gap forces it (e.g.
  `UITextField` for very specific keyboard control). Document each
  exception.
- **Swift 5.9.** Strict-concurrency set to `minimal` until codebase
  stabilises; bump to `complete` later.
- **iOS 17.0 minimum.** Lets us use `Observation`, `.sensoryFeedback`,
  the new `ScrollView` APIs, and `.symbolEffect` without backporting.
- **iPhone only for v1.** iPad / Mac Catalyst is a later decision.
